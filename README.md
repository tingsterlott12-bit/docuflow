# DocuFlow — 3D Interactive FlipBook Publication Platform

DocuFlow is a production-grade, open-source 3D FlipBook platform built with Next.js 14, StPageFlip, Tailwind CSS, and Supabase.

- **GitHub Repository**: [tingsterlott12-bit/docuflow](https://github.com/tingsterlott12-bit/docuflow)
